# Тихая бесконечность — Android starter

Это стартовый нативный проект на Kotlin + Jetpack Compose.

## Что уже есть
- экран острова с нажатием на Источник;
- пассивный генератор и улучшение силы касания;
- опыт и повышение уровня;
- выбор одной из трёх случайных карт при повышении уровня;
- четыре постоянных навыка;
- локальное сохранение и начисление офлайн-производства (до 8 часов);
- вкладки «Остров», «Карты», «Навыки», «Архив».

## Как открыть
1. Установи Android Studio.
2. Распакуй архив.
3. В Android Studio выбери **Open** и укажи папку `TihayaBeskonechnost`.
4. Дождись Gradle Sync. Для сборки нужен Android SDK 36 и JDK 17 или совместимая JDK.
5. Подключи Android-телефон с включённой USB-отладкой либо создай эмулятор.
6. Нажми Run ▶.

## Как собрать APK
В Android Studio: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Важно
Это первая игровая сборка (v0.1.0), а не финальный релиз. Она нужна, чтобы запустить основу на устройстве и дальше проверять баланс, интерфейс и механику на реальном телефоне.
